Measure all four sides and both diagonals if you can; at least five are needed to fix the shape. The UWB column is only for comparison.

2. Heights (feet above the floor)

All anchors at ft

X/Y account for the tag's height either way, so people of any height read correctly. The height reading is best with the anchors low (0 = on the floor) and the tag well above them; it assumes the tag is above the anchors. Tape distances above are measured along the floor.

3. Grid corner each anchor stands for

The tag's X/Y are reported in these grid units: the measured shape is mapped onto them, so a 4×6 ft rectangle still runs from −1 to 1 on both axes, with the feet shown underneath.
