Anchor setup

1. Tape-measured distance between each pair of anchors (feet)

Measure all four sides and both diagonals if you can; at least five are needed to fix the shape. Any shape works (square, rectangle, …). The UWB column is only for comparison.

2. Grid corner each anchor stands for

The tag's X/Y are reported in these grid units: the measured shape is mapped onto them, so a 4×6 ft rectangle still runs from −1 to 1 on both axes, with the feet shown underneath.
